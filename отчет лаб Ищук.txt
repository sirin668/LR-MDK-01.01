Отчёт Задача 3 Индекс массы тела (ИМТ)
 
Подзадача: Ввод роста
Описание: Запрос и валидация роста (см)

Подзадача: Ввод веса
Описание: Запрос и валидация веса (кг)

Подзадача: Расчёт ИМТ
Описание: Вычисление индекса массы тела по росту и весу

Подзадача: Определение категории
Описание: Определение категории по значению ИМТ

Подзадача: Получение рекомендации
Описание: Подбор текста рекомендации по категории

Подзадача: Вывод результата
Описание: Вывод ИМТ, категории и рекомендации

Функция 1: ReadHeight
Тип возврата: double
Аргументы: нет
Назначение: запрашивает у пользователя рост, проверяет корректность ввода (число, больше нуля), при ошибке повторяет запрос.
Возвращает: рост в сантиметрах.

Функция 2: ReadWeight
Тип возврата: double
Аргументы: нет
Назначение: запрашивает вес, проверяет корректность (число, больше нуля), при ошибке повторяет запрос.
Возвращает: вес в килограммах.

Функция 3: CalculateBMI
Тип возврата: double
Аргументы:

double height — рост (см)

double weight — вес (кг)
Назначение: переводит рост в метры и вычисляет ИМТ как отношение веса к квадрату роста.
Возвращает: значение ИМТ.

Функция 4: GetCategory
Тип возврата: string
Аргументы:

double bmi — значение ИМТ
Назначение: определяет категорию по ИМТ: менее 18,5 — «Недостаточный вес»; от 18,5 до 25 — «Норма»; от 25 до 30 — «Избыточный вес»; свыше 30 — «Ожирение».
Возвращает: название категории.

Функция 5: GetRecommendation
Тип возврата: string
Аргументы:

string category — категория ИМТ
Назначение: возвращает текст рекомендации: при недостаточном весе — увеличить калорийность рациона; при норме — поддерживать текущий образ жизни; при избыточном весе — увеличить физическую активность; при ожирении — обратиться к врачу.
Возвращает: текст рекомендации.

Функция 6: PrintResult
Тип возврата: void
Аргументы:

double height — рост (см)

double weight — вес (кг)

double bmi — значение ИМТ

string category — категория

string recommendation — рекомендация
Назначение: выводит рост, вес, ИМТ, категорию и рекомендацию.

Функция 7: Main
Тип возврата: void
Аргументы: string[] args
Назначение: организует вызовы остальных функций.

Алгоритм решения подзадач
Вызвать ReadHeight() → получить рост.

Вызвать ReadWeight() → получить вес.

Вызвать CalculateBMI(height, weight) → получить значение ИМТ.

Вызвать GetCategory(bmi) → получить категорию.

Вызвать GetRecommendation(category) → получить рекомендацию.

Вызвать PrintResult(height, weight, bmi, category, recommendation).

Реализуется написанным кодом

Итог: задача решена, программа рассчитывает ИМТ, определяет категорию и выводит рекомендацию.

Пример:
Введите рост (см): 175
Введите вес (кг): 68
Рост: 175 см
Вес: 68 кг
ИМТ: 22,2
Категория: Норма
Рекомендация: Поддерживайте текущий образ жизни.
