Отчет по 2 лабораторной работе Анастасия Ищук
Разработка консольного приложения для цветочного магазина и оформления заказа.
Подзадачи
Подзадача: Вывод ассортимента
Описание: Отображение списка цветов с номерами, названиями, ценами и остатками на складе.

Подзадача: Ввод номера цветка
Описание: Запрос и валидация номера цветка (0–5), где 0 — завершение заказа.

Подзадача: Ввод количества
Описание: Запрос и валидация количества штук (целое число, не меньше 1).

Подзадача: Накопление заказа
Описание: Суммирование количества по каждому цветку в отдельном массиве заказа.

Подзадача: Проверка наличия на складе
Описание: Определение, хватает ли каждого заказанного цветка на складе.

Подзадача: Списание товара и расчёт стоимости
Описание: Уменьшение остатков и подсчёт итоговой суммы заказа.

Подзадача: Вывод остатков
Описание: Отображение актуальных остатков по каждому цветку после обработки заказа.

Функция 1: PrintAssortment
Тип возврата: void
Аргументы: нет
Назначение: выводит на экран список цветов с номерами, названиями, ценами и остатками.
Возвращает: ничего.

Функция 2: GetValidIntInput
Тип возврата: int
Аргументы:

string message — текст приглашения к вводу

int min — минимально допустимое значение

int max — максимально допустимое значение

Назначение: запрашивает у пользователя целое число, проверяет корректность (число, входит в диапазон), при ошибке повторяет запрос.
Возвращает: корректное целое число.

Функция 3: ProcessOrder
Тип возврата: void
Аргументы:

int[] orderQuantities — массив количества по каждому цветку

Назначение: проверяет, хватает ли всех цветов на складе. Если да — списывает товар и выводит стоимость заказа. Если нет — выводит, какого цветка не хватает, и не выполняет заказ.
Возвращает: ничего.

Функция 4: PrintStocks
Тип возврата: void
Аргументы: нет
Назначение: выводит остатки по каждому цветку на складе.
Возвращает: ничего.

Функция 5: Main
Тип возврата: void
Аргументы: string[] args
Назначение: организует вызовы остальных функций.

Алгоритм решения подзадач
Вызвать PrintAssortment() → вывести ассортимент.

Создать массив orderQuantities[5] для хранения заказа.

В цикле:

Вызвать GetValidIntInput("Введите номер цветка (0 - конец заказа): ", 0, 5) → получить номер.

Если номер = 0 → выйти из цикла.

Вызвать GetValidIntInput("Введите количество: ", 1, int.MaxValue) → получить количество.

Прибавить количество к orderQuantities[номер - 1].

Вызвать ProcessOrder(orderQuantities):

Пройти по массиву, проверить, хватает ли каждого цветка. Если нет — вывести сообщение о нехватке и не списывать.

Если всё хватает — списать товар, посчитать сумму и вывести её.

Вызвать PrintStocks() для вывода остатков.

Завершить программу.

Итог: задача решена. Программа выводит ассортимент, принимает заказ с валидацией ввода, проверяет наличие на складе, списывает товар, рассчитывает стоимость и выводит остатки.
